➡️ **Online-Kurs:**

## Einleitung

Dieses Dokument ist eine **Lernressource** für Studierende und erhebt keinen Anspruch auf Vollständigkeit. Einige Themen erfordern die Anleitung durch einen Dozenten, und verschiedene Aspekte der Webentwicklung wurden bewusst ausgelassen.

Diese Ressource ist Teil einer Reihe von Dokumenten zum Thema **Webentwicklung**, ein Thema, das der Autor bereits zuvor anhand von zwei Technologien vertieft hat:

* **Java**
* **PHP**

Diese Dokumente weisen eine **ähnliche didaktische Struktur** auf, sodass die verschiedenen Technologien anhand vergleichbarer Beispiele gegenübergestellt werden können.

## Didaktischer Ansatz

Im Gegensatz zu vielen Büchern über ASP.NET konzentriert sich diese Ressource nicht sofort auf die Vorstellung, dass eine ASP.NET-Webanwendung wie eine **Windows-Anwendung** entwickelt werden kann.

In der traditionellen Literatur zu ASP.NET:

* wird die Benutzeroberfläche oft in IDEs wie **Visual Studio .NET** oder **WebMatrix** erstellt
* werden die **grafischen Steuerelemente** in eine visuelle Oberfläche eingefügt;
* verfügen diese Steuerelemente über **Eigenschaften, Methoden und Ereignisse**;

In diesem Dokument werden diese Konzepte bewusst **erst später im Kurs** vorgestellt, da sie zwar als wichtig, aber **nicht grundlegend** für das Verständnis der Webentwicklung angesehen werden.

## Hauptziel

Der erste Teil des Dokuments konzentriert sich auf die **Grundlagen der Webentwicklung**, unabhängig von der verwendeten Technologie (Java, PHP oder ASP.NET).

Besonderes Augenmerk wird auf die Architektur gelegt:

**MVC — Model / View / Controller**

Diese Architektur wird häufig für die Entwicklung strukturierter und leicht zu verwaltender Webanwendungen empfohlen.

Der MVC-Ansatz ist jedoch relativ unvereinbar mit der Philosophie von ASP.NET, eine Webanwendung wie eine Windows-Anwendung zu entwerfen. Aus diesem Grund werden die spezifischen Mechanismen von ASP.NET zur Steigerung der Produktivität **im zweiten Teil des Kurses** behandelt.

## Verwendete Tools

Dieses Dokument konzentriert sich ausschließlich auf **im Internet kostenlos verfügbare Tools**, damit die Teilnehmer:

* die vorgestellten Beispiele nachbauen und damit experimentieren;

Ein Anhang mit dem Titel **„Web-Tools“** erklärt, wie man diese Tools erhält und installiert.
